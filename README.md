## ✨ About

Welcome to my personal portfolio!

This website showcases who I am, the projects I've built, the technologies I work with, and my journey as a developer.

Inspired by the cinematic atmosphere of **Dune**, the portfolio transforms a traditional developer website into an interactive desert experience. From layered sand dunes and drifting particles to an animated ornithopter, every detail is designed to create an immersive experience.

Built entirely with **HTML, CSS, and vanilla JavaScript**, the website requires no frameworks, build tools, or external JavaScript dependencies.

## 🎬 Features

The portfolio combines cinematic visuals with interactive elements to make browsing an experience of its own.

### 🌵 Cinematic Desert Experience

- **Cinematic Intro:** A film-style opening featuring a black screen and animated name reveal.
- **Layered Dunes:** A desert landscape featuring layered sand dunes, a mysterious monolith, and a lone figure.
- **Atmospheric Lighting:** Hazy sun, lens flares, twinkling stars, two drifting moons, and shooting stars.
- **Flying Ornithopter:** An animated ornithopter with flapping wings crossing the desert sky.
- **Wind Effects:** Drifting sand particles, atmospheric dust, and a subtle camera push-in.
- **Film Aesthetic:** Widescreen cinematic bars and a subtle film-grain overlay.

### 🖱️ Interactive Experience

- **Interactive Parallax:** Desert layers respond to mouse movement, touch gestures, and scrolling.
- **Interactive Typography:** Letters in my name lift and glow as the cursor approaches.
- **Sandstorm Effect:** Click and hold inside the hero section to accelerate the drifting sand.
- **Custom Cursor:** Smooth cursor ring, central dot, particle trails, click ripples, and contextual OPEN labels.
- **Magnetic Buttons:** Buttons subtly move toward the cursor.
- **3D Tilt Cards:** Project cards respond dynamically to cursor movement.
- **Spotlight Effects:** Project rows feature interactive hover lighting.

### ⚡ Scroll & Motion

- Scroll-triggered animations with blur, sliding, and staggered reveals.
- Alternating project animations from left and right.
- Scrambling text headings that resolve into their original words.
- Interactive text highlighting in the About section.
- Scroll-speed skew effects on project lists and technology columns.
- Reading progress indicator and active-section tracking.
- Back-to-top button for easy navigation.
- Two continuously scrolling technology marquees moving in opposite directions.

### 🎨 Design & Accessibility

- Fully responsive layout for mobile, tablets, laptops, and large displays.
- Light and dark themes with a manual toggle and system preference detection.
- Semantic HTML and accessible page landmarks.
- Keyboard-friendly navigation and visible focus indicators.
- Reduced-motion support through `prefers-reduced-motion`.
- Touch-friendly interactions with mouse-specific cursor effects disabled on touch devices.

## 💻 Run Locally

Getting started is simple. No installation or additional dependencies are required.

**1. Clone the repository**

```bash
git clone https://github.com/AmlanShanker/Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Portfolio
```

**3. Open the website**

Simply open `index.html` in your preferred browser.

Alternatively, start a local development server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🎨 Customization

The entire website is contained in a single `index.html` file, making customization straightforward.

| What to Customize | Where to Look |
|---|---|
| Colors and themes | CSS `:root` variables at the beginning of the style block |
| Name, role, and tagline | `.title` block inside `<header class="hero">` |
| About content | `<section class="s" id="about">` |
| Projects | Project `.row` links inside the work section |
| Technology stack | `.cast` columns inside the stack section |
| Contact links | `.cta` buttons inside `<section class="end" id="contact">` |
| Technology marquee | `<span>` elements inside `#mt` |

## 🌐 Deployment

This portfolio is deployed using **GitHub Pages**.

To deploy your own changes:

1. Push your updated `index.html` to the repository's `main` branch.
2. Open your repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click **Save**.

Your website will be available at:

**https://amlanshanker.github.io/Portfolio/**
